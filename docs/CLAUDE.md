# 小鱼记账 — 项目文档与协作规则

> 本文件是项目的"总章程":包含产品需求、与用户的协作规则、当前进度。
> 每次开始工作前必须先读本文件。

## 一、项目简介

- **产品名称**:小鱼记账
- **产品定位**:个人日常花销记账桌面应用,只记人民币支出
- **目标平台**:Windows + macOS 桌面端
- **数据原则**:所有数据保存在用户自己的电脑上,离线可用;不注册、不登录、不上传

## 二、与用户的协作规则(整个项目期内必须严格遵守)

1. 用户是完全不懂编程的小白、首次使用 Claude Code。**所有沟通使用中文、大白话,避免专业术语**;必须解释时用生活化比喻。
2. **任何技术选型或技术方案,必须先列出 2~3 个可行方案,用大白话解释每个方案对用户的真实影响(安装包大小、使用体验、开发风险、未来扩展),由用户拍板决定。不得擅自替用户做技术决定。**
3. 解释方案时,重点回答"这对用户意味着什么",而不是罗列技术参数。
4. 涉及用户资金数据:隐私与数据安全优先,默认全部本地存储,未经用户明确同意不得将任何数据传到网上。
5. 重大产品变更(新增功能、改动记账逻辑、改动分类体系)必须先征求用户意见。
6. 每个开发阶段完成后,用大白话向用户汇报:做了什么、怎么验证、下一步是什么。
7. 技术细节取舍说明:凡影响产品体验或开发方向的技术选择,一律按第 2 条执行;纯内部实现细节(如某个小工具库的选择),Claude 可自行决定,但要在当次汇报中用一句话说明理由,用户随时可以推翻。

## 三、产品文档(v1 范围)

### 3.1 核心功能

1. **记一笔(核心功能)**:记录一次花销
   - 金额:人民币,单位为元,精确到分(如 12.50)
   - 消费日期:默认今天,可修改
   - 分类:两级,先选一级大类,再选二级小类(分类表见 3.3)
   - 备注:可选,随手写几个字(如"和同事午饭")
   - 支付方式:可选(见 3.4)
2. **账单列表**:按时间倒序浏览所有记录;按月切换查看;支持按分类筛选和关键词搜索;可编辑、删除任意一条记录
3. **统计概览**:今日支出、本月支出、本月日均支出;本月各一级分类支出占比(饼图);近 6 个月支出趋势(柱状图);点击某个分类可下钻查看其二级分类明细
4. **分类管理**:内置默认分类(见 3.3);用户可自行新增、重命名、隐藏分类
5. **数据备份**:一键导出全部账单为 Excel/CSV 文件,方便另行保存

### 3.2 界面结构(规划)

- 左侧:导航栏(记一笔 / 账单 / 统计 / 分类管理)
- 主区域:对应页面内容
- 风格:清爽简洁,支持浅色 / 深色主题

| 一级分类 | 二级分类 |
|---|---|
| 餐饮饮食 | 早餐、午餐、晚餐、夜宵、外卖、零食饮料、水果、聚餐请客 |
| 交通出行 | 公交地铁、打车网约车、火车高铁、飞机、加油充电、停车过路费、共享单车 |
| 购物消费 | 服饰鞋包、数码电器、日用品、美妆护肤、烟酒茶叶、其他购物 |
| 居住生活 | 房租房贷、水电燃气、物业费、网费话费、家居维修、日常耗材 |
| 娱乐休闲 | 电影演出、游戏充值、运动健身、旅游度假、图书影音、休闲消遣 |
| 医疗健康 | 门诊挂号、药品、住院、体检、保健品、医疗器具 |
| 学习教育 | 学费、培训课程、书籍资料、文具、考试报名 |
| 人情往来 | 红包礼金、请客送礼、孝敬长辈、慈善捐款 |
| 金融支出 | 保险保费、贷款还款、手续费利息 |
| 其他 | 其他支出 |

### 3.4 支付方式(内置默认)

微信、支付宝、现金、银行卡、信用卡、其他

### 3.5 暂不包含(v1 不做,未来可讨论)

- 收入记录(当前只记花销)
- 预算设置、超支提醒
- 云同步、多设备同步、手机端
- 导入银行流水
- 多账本、家庭共享记账

## 四、技术方案(已确定 — 2026-09-14 由用户选定)

| 项目 | 选择 | 一句话理由(用户视角) |
|---|---|---|
| 桌面框架 | Electron | 最成熟稳定,开发顺利、问题好解决;可接受安装包较大 |
| 界面框架 | Vue 3 | 中文资料多、上手简单,适合中小型应用 |
| 数据存储 | SQLite(本地) | 专业记账软件同款,账单再多也流畅,数据只存在用户电脑上 |

必要运行环境:Node.js(Electron 的底层基础,需在开发电脑安装)。其余配套小工具(如打包工具)由 Claude 按第 2 章第 7 条自行决定并在汇报中说明。
